# 📊 Análise Salarial de Profissionais da Área de Dados

Dashboard interativo desenvolvido com Python, Pandas, Plotly e Streamlit para explorar informações salariais de profissionais da área de dados.

O projeto é uma extensão dos estudos realizados durante a **Imersão Dados com Python da Alura**, com foco na aplicação prática de técnicas de tratamento, análise e visualização de dados.

### 🔗 Acesse o dashboard

**[Visualizar aplicação interativa](https://imersao-dados-nando.streamlit.app/)**

## Tecnologias utilizadas

- Python
- Pandas
- NumPy (atividades do notebook)
- Plotly
- Streamlit
- Google Colab (atividades iniciais)

## Funcionalidades

- Filtros por ano, cargo, senioridade e modalidade de trabalho.
- Indicadores de salário médio e mediano anual.
- Quantidade de registros e cargos distintos.
- Comparação salarial por nível de senioridade.
- Análise dos cargos mais frequentes.
- Distribuição salarial e modalidades de trabalho.
- Comparação salarial por localização das empresas.
- Visualização e exportação dos dados filtrados em CSV.

## Tratamento dos dados

Foram aplicadas operações de exploração, limpeza e transformação utilizando Pandas, incluindo:

- Identificação e tratamento de valores ausentes.
- Renomeação de colunas.
- Conversão de tipos de dados.
- Padronização de categorias.
- Agrupamento e cálculo de indicadores estatísticos.

## Fonte dos dados

Dataset público disponibilizado no [repositório data-jobs](https://github.com/guilhermeonrails/data-jobs).

Os valores salariais apresentados são anuais e expressos em dólares americanos (USD).
